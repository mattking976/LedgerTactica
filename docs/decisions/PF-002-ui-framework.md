# PF-002: UI Framework Decision

## Status

Accepted

## Decision

The project will utilise Tailwind CSS for styling.

## Reasoning

Tailwind provides:

- Rapid development
- Consistent styling
- Responsive layouts
- Reduced CSS maintenance

## Alternatives Considered

### Traditional CSS

Rejected.

Reason:

Greater maintenance overhead.

### Bootstrap

Rejected.

Reason:

Less flexibility and greater dependency on pre-built patterns.

## Consequences

Frontend components should be styled using Tailwind utility classes where possible.
